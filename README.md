1. Function hitung_parkir()

Function ini digunakan untuk menghitung biaya parkir berdasarkan jenis kendaraan dan lama parkir. Function menerima dua parameter, yaitu kendaraan dan jam. Di dalam function digunakan percabangan if dan elif untuk menentukan tarif parkir mobil atau motor. Setelah biaya dihitung, hasilnya dikembalikan menggunakan return.

2. Input Data

Program meminta pengguna memasukkan jenis kendaraan, jam masuk, dan jam keluar. Data tersebut nantinya digunakan untuk menghitung lama kendaraan berada di area parkir.

3. Menghitung Lama Parkir

Lama parkir diperoleh dari hasil pengurangan jam keluar dengan jam masuk. Nilai inilah yang akan dikirim ke function sebagai lama waktu parkir.

4. Memanggil Function

Setelah lama parkir diketahui, program memanggil function hitung_parkir() dengan mengirimkan jenis kendaraan dan lama parkir sebagai argumen. Function kemudian mengembalikan total biaya parkir yang disimpan ke dalam variabel hasil.

5. Menampilkan Hasil

Pada bagian akhir, program menampilkan informasi berupa jenis kendaraan, jam masuk, jam keluar, lama parkir, dan total biaya parkir sehingga pengguna dapat melihat hasil perhitungan yang telah dilakukan.
